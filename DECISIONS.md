# Architecture & trade-offs

- pnpm workspaces keep the React app, Express API, and shared contracts in one TypeScript repository. Strict shared Zod schemas and inferred types define health, authentication, discovery, catalogue, engagement, admin, archive, pagination, and error contracts at runtime and compile time.
- `app.ts` is the API composition root for global CORS/body parsing, feature-router mounting, and error boundaries. Health, authentication, discovery, catalogue, engagement, admin, and OpenAPI remain feature-oriented modules with narrow store interfaces; Prisma projections select only each response's required fields.
- PostgreSQL persistence uses two Prisma migrations, uniqueness constraints, and explicit `archivedAt`/`removedAt` fields. Archive and remove operations preserve records and relationships. The deterministic idempotent seed creates 240 active books, 12 active genres, and two hashed-password demo users without network access; its genre reconciliation preserves an archived seed when an active librarian-created replacement owns the same name or slug.
- Public discovery returns exactly the available set up to six newest active books with a book-ID tie-breaker and preview-only fields. Reader catalogue queries are active-only, search title/author only, use stable sorts, and report archived detail as not found.
- Favourite genres are a full ordered replacement of zero to five unique active genres. Personalised results cap at six and follow preference, newest, and ID order while excluding the visible reading list. Reading-list upsert restores soft-removed state, and archived books remain as reader-safe unavailable history that can be removed but not updated.
- Librarian book and genre mutations use validated full inputs and transactional persistence. Books retain archived historical genre associations during edits and retain all associations when archived; restoration requires an active genre. Genre archive is blocked when it would leave an active book without another active genre, and active name/slug conflicts remain enforced across create, update, and restore.
- Authentication uses bounded scrypt password verification and a short-lived HS256 token in an HTTP-only, `SameSite=Lax` cookie. Roles are reloaded from server-side users, not trusted from the JWT or client. Exact-origin credentialed CORS, `Vary: Origin`, no-store rejection responses, private/no-store protected data, generic credential errors, and structured oversized-body handling are proportionate controls for the local demo.
- React Router separates the public landing page, protected reader pages, and librarian-only Back Room. A single authentication provider bootstraps the session; relative credentialed `/api` calls validate shared contracts and never expose the JWT to JavaScript storage. Catalogue state lives in the URL, and shared components implement responsive, keyboard/focus, status, archive, and reduced-motion behavior across reader and admin flows. Visual genre truncation keeps a complete assistive-text list, while Fraunces Variable and IBM Plex Mono are bundled locally through Fontsource with swap behavior and no CDN dependency.
- OpenAPI 3.0.3 is generated from the Zod contracts with `@asteasolutions/zod-to-openapi` 7.3.4 and served through local `swagger-ui-express` 5.0.1. Its public cookie scheme describes the contract without publishing credentials, hashes, JWT secrets, or examples; 18 paths and 24 implemented operations are documented, including structured non-admin payload-too-large responses.
- Docker Compose is intentionally a trusted-local take-home environment: it exposes broad host ports, uses known privileged database credentials, root/dev-tool-heavy containers, Vite serving, and mutable base tags. Internet deployment is a non-goal and would require container/network hardening, rate limits, production password cost, token revocation/key rotation, a reviewed explicit CSRF strategy, security headers, privileged-action audit logging, and structured observability.
- Automated tests use mocked Prisma stores for route and concurrency behavior rather than a database-backed concurrent integration suite. The final browser-backed QA service was unavailable, so rendered responsive geometry, complete physical-keyboard journeys, forced-colour/reduced-motion runtime behavior, console/network state, and rendered Swagger interaction remain manual checks. A registry-backed advisory scan also remains required because the audit environment could not reach the package registry.
